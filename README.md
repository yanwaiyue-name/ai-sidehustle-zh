## 这本书和别的有什么不一样

网上教 AI 副业的，一类喊「月入十万」，一类卖课。两类都没告诉你**具体账怎么算、失败率多少、要投多少时间**。

每一条都按同一个格式写（沿用《学生版·高性价比人生指南》的写法）：

| 字段 | 回答什么 |
| --- | --- |
| 成本 | 要花多少钱、多少时间、要不要长期自律 |
| 说人话 | 这件事到底是什么，不用术语 |
| 收益 | 具体数字或公开数据，查不到就写「没有公开数据」 |
| 为什么 | 这条路背后的机制 |
| 证据等级 | A（有官方/平台原文）/ B（有统计/报告）/ C（只有个案经验） |
| 来源 | 机构、文件名、链接 |
| 备注 | 什么情况下这条不适用 |

**证据 C 级必须写清「这是经验判断，没有权威数据」**，不许写成 A 级的口气。
