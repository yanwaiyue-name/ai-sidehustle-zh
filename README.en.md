## How this differs

Most "AI side-hustle" lists online are clickbait. This book only includes paths you can start today, with the math spelled out and backed by public data or official sources.

Every entry follows a fixed format (borrowed from *Student's High-Value Life Guide*):

| Field | Answers |
| --- | --- |
| Cost | money / time / discipline required |
| Plain | what this actually is, no jargon |
| Income | concrete numbers or public data; "no public data" if none |
| Why | the mechanism behind it |
| Evidence | A (official source) / B (stats) / C (anecdote only) |
| Source | org, doc name, link |
| Note | when it doesn't apply |

**C-level entries must state "this is experience-based, no authoritative data"** — never written in A-level tone.
